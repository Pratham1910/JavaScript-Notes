## Complexity Cheat Sheet

  Operation                 Time   Space
  ----------------------- ------ -------
  Array Access              O(1)    O(1)
  Array Search              O(n)    O(1)
  Insert End                O(1)    O(1)
  Insert Middle             O(n)    O(1)
  Delete                    O(n)    O(1)
  HashMap Search            O(1)    O(n)
  Stack Push/Pop            O(1)    O(n)
  Queue Enqueue/Dequeue     O(1)    O(n)
