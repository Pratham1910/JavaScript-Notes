## 1. Getting Started

  

### How to open DevTools:

-   **Right-click** anywhere and select **Inspect**.

-   **F12** (Windows/Linux).

-   **Ctrl + Shift + I** (Windows/Linux).

  

### 🪟 Window Management (Docking)

You can change where DevTools appears:

1.  Click the **three dots** (⋮) in the top-right of DevTools.

2.  Choose **Dock side**:

    -   **Undock into separate window**: Best for multi-monitor setups.

    -   **Dock to left/right**: Best for wide screens.

    -   **Dock to bottom**: The classic view.

## 2. The Elements Panel

  

This is where you inspect the DOM and live-edit CSS.

  

### 🎨 Live Editing

-   **Double-click** any tag or attribute to change it live.

-   **CSS Styles**: Click on any property in the "Styles" tab to toggle it or change the value. Use the arrow keys (↑/↓) to increment numbers.

-   **The Color Picker**: Click the color square next to a CSS color to open a visual picker with contrast ratio checks.

  

### ⚓ Forced States

Want to style a hover effect without holding your mouse over the element?

1.  Right-click the element in the DOM tree.

2.  Select **Force state** > **:hover**.

  

### 📦 The Box Model

Scroll to the bottom of the "Styles" tab to see the visual padding, border, and margin of the selected element.

## 3. The Console: JavaScript's Playground

  

### 🚀 Beyond `console.log()`

```javascript

console.table(myData);      // Displays arrays/objects as a beautiful table

console.warn("Watch out!"); // Yellow warning

console.error("Oops!");     // Red error

console.group("User Data"); // Groups multiple logs together

console.log("Name: Antigravity");

console.groupEnd();

```

  

### 🪄 Magic Variables

-   **`$0`**: Returns the element currently selected in the Elements panel.

-   **`$_`**: Returns the value of the last evaluated expression.

-   **`$$('div')`**: Shortcut for `document.querySelectorAll('div')`.

-   **`copy($0)`**: Copies the selected element's HTML to your clipboard.

  

### 🌐 Understanding the `window` Object

The `window` object is the "King" of the browser. Everything you see and do in JavaScript happens inside it.

-   Type `window` in the console to see all available browser APIs.

-   **`window.location`**: Check or change the current URL.

-   **`window.innerWidth`**: Check the width of the viewport.

-   **`window.scrollTo(0, 0)`**: Jump to the top of the page.

-   **Global Variables**: Any variable you create without `let`, `const`, or `var` (or in the global scope) becomes a property of `window`.

## 4. The Sources Panel: Pro Debugging

  

Stop using `console.log()` to debug logic! Use **Breakpoints**.

  

### 🛑 Breakpoints

1.  Open your JS file in the Sources panel.

2.  Click a line number to set a breakpoint.

3.  Refresh the page. The code will **pause** exactly at that line.

4.  You can now hover over variables to see their values at that exact moment.

  

### 📝 Snippets

If you have a script you run often (e.g., a script to clear all local storage), save it in **Sources > Snippets**. It will be available on every website you visit.

## 5. The Network Panel: API & Speed

  

### 📉 Throttling

Test how your site feels on a slow connection.

-   Click the **No throttling** dropdown.

-   Select **Fast 3G** or **Slow 3G**.

  

### 🔍 Inspecting Requests

-   Click on any request to see its **Headers** (what you sent) and **Response** (what the server sent back).

-   Filter by **Fetch/XHR** to see only API calls.

## 6. The Application Panel: Storage

  

This is your browser's database.

-   **Local Storage**: Data that stays even after you close the browser.

-   **Session Storage**: Data that clears when the tab is closed.

-   **Cookies**: Small pieces of data sent with every request.

-   **Clear Storage**: One button to wipe everything and start fresh.

## 7. Pro Tricks & Shortcuts

  

### ⌨️ The Command Menu (`Ctrl + Shift + P`)

Like VS Code's Command Palette, you can do anything from here:

-   Type **"Screenshot"** to capture a full-page screenshot.

-   Type **"Theme"** to switch to Dark Mode.

-   Type **"Disable JavaScript"** to test your site's fallback.

  

### 📸 Capture Node Screenshot

1.  Select an element in the **Elements** panel.

2.  Open the **Command Menu** (`Ctrl + Shift + P`).

3.  Type **"Capture node screenshot"**.

4.  It will save an image of *only* that specific element.

  

### 🔍 Find Anything (`Ctrl + Shift + F`)

Search for any text, CSS class, or variable name across **all** files loaded on the page.

## 🏁 Final Tip

The best way to learn DevTools is to **break things**. Open it on your favorite website, delete elements, change colors, and see how it works!
