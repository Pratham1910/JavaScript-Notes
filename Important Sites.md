# 🚀 Important Developer Resources

  

A curated list of websites and tools to help developers build, design, and learn more effectively.

  

---

  

## 📚 Documentation & Learning

*   **[MDN Web Docs](https://developer.mozilla.org/)**: The definitive resource for HTML, CSS, and JavaScript documentation.

*   **[web.dev](https://web.dev/)**: Guidance from Google's web platform team on modern web best practices.

*   **[W3Schools](https://www.w3schools.com/)**: Easy-to-follow tutorials for web development beginners.

*   **[FreeCodeCamp](https://www.freecodecamp.org/)**: A massive library of certifications and coding challenges.

*   **[Frontend Masters](https://frontendmasters.com/)**: High-quality video courses from industry experts.

  

## 🎨 Design & Inspiration

*   **[Dribbble](https://dribbble.com/)**: A place to show and tell, promote, discover, and explore design.

*   **[Behance](https://www.behance.net/)**: Adobe's social media platform to showcase and discover creative work.

*   **[Awwwards](https://www.awwwards.com/)**: Awards that recognize the talent and effort of the best web designers.

*   **[Pinterest](https://www.pinterest.com/)**: Great for mood boards and UI/UX inspiration.

*   **[Mobbin](https://mobbin.com/)**: The world's largest mobile app design reference library.

  

## 🖼️ Stock Media (Images, Video, Illustrations)

*   **[Unsplash](https://unsplash.com/)**: Beautiful, free images and photos that you can download and use.

*   **[Pexels](https://www.pexels.com/)**: Free stock photos & videos shared by talented creators.

*   **[Pixabay](https://pixabay.com/)**: Over 2.7 million+ high-quality stock images, videos, and music.

*   **[undraw.co](https://undraw.co/)**: Open-source illustrations for every project you can imagine.

*   **[Humaaans](https://www.humaaans.com/)**: Mix-and-match illustrations of people with a design library.

  

## ✨ Icons & Fonts

*   **[Remix Icon](https://remixicon.com/)**: A set of open-source neutral style system symbols.

*   **[Font Awesome](https://fontawesome.com/)**: The internet's most popular icon set and toolkit.

*   **[Heroicons](https://heroicons.com/)**: Beautiful hand-crafted SVG icons, by the makers of Tailwind CSS.

*   **[Google Fonts](https://fonts.google.com/)**: Making the web more beautiful, fast, and open through great typography.

*   **[Lucide Icons](https://lucide.dev/)**: Beautiful & consistent icons, a community-run fork of Feather Icons.

  

## 🛠️ Tools & Utilities

*   **[Can I Use](https://caniuse.com/)**: Up-to-date browser support tables for modern web technologies.

*   **[Squoosh](https://squoosh.app/)**: Google's image compression tool to reduce file size without losing quality.

*   **[Carbon](https://carbon.now.sh/)**: Create and share beautiful images of your source code.

*   **[Excalidraw](https://excalidraw.com/)**: Virtual whiteboard for sketching hand-drawn like diagrams.

*   **[Responsively App](https://responsively.app/)**: A must-have tool for responsive web development.

*   **[TinyPNG](https://tinypng.com/)**: Smart WEBP, PNG, and JPEG compression.

  

## ⚔️ Challenges & Practice

*   **[CSS Battle](https://cssbattle.dev/)**: Use your CSS skills to replicate targets with the smallest possible code.

*   **[Frontend Mentor](https://www.frontendmentor.io/)**: Solve real-world HTML, CSS, and JS challenges while building portfolio projects.

*   **[Codewars](https://www.codewars.com/)**: Achieve mastery through "kata" (small coding exercises).

*   **[LeetCode](https://leetcode.com/)**: The best platform to help you enhance your skills and prepare for technical interviews.

*   **[Exercism](https://exercism.org/)**: Code practice and mentorship for everyone.

  

## 🚀 Deployment & Hosting

*   **[Vercel](https://vercel.com/)**: The best platform for frontend developers to deploy websites instantly.

*   **[Netlify](https://www.netlify.com/)**: An all-in-one platform for automating modern web projects.

*   **[GitHub Pages](https://pages.github.com/)**: Websites for you and your projects, hosted directly from your GitHub repository.

*   **[Railway](https://railway.app/)**: Infrastructure that can be provisioned instantly to host apps of any scale.
